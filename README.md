# CacaoPhotoSlide

写真のフォルダをドロップすると、全画面のスライドショーにする Mac アプリ。音楽はなし。
既定は **Ken Burns**（写真がゆっくり寄ったり流れたりしながら、次の写真にクロスフェード）。

| できること | 中身 |
|---|---|
| フォルダを D&D | ウインドウに落とすか、Dock のアイコンに落とす。「開く…」（⌘O）でも |
| 開始写真 | 全部のサムネイルが並ぶ。クリックした写真から始める（ダブルクリックですぐ開始） |
| 選んだ写真だけ | ⌘クリック / ⇧クリックで 2 枚以上選ぶと、その写真だけを流す（⇧⌘A で全部、Esc で解除） |
| mp4 に書き出す | 画面と同じ動き（Ken Burns・切り替え・順番・選んだ写真）を H.264 の mp4 に。16:9 で 720p / 1080p / 1440p / 4K、30 / 60 fps。音声も入る |
| タイムライン | 所要時間（枚数 × 表示時間）と写真の区切りを帯で表示。音声ファイルを落とした位置に置き、ドラッグで動かす。段（トラック）を分ければ重ねて置け、重なりは混ざる（クロスフェード）。曲の範囲（開始位置〜終了位置）・音量・フェードイン／アウト |
| 写真を外す | サムネイルの右クリック「この写真を外す」か、選んで Delete。流さず、書類にもコピーしない。「外した N 枚を戻す」で戻る |
| 書類 .cpsd | フォルダ形式の書類に保存（⌘S）。設定・タイムライン・音声のコピーに加え、写真も（選んだ写真だけ、なければ全部）書類の中にコピーできる |
| 全画面 / 別ウインドウ | 設定「表示先」で選ぶ。全画面はメニューバー・Dock・カーソルを隠して画面を黒で覆う。別ウインドウは普通の窓（16:9、大きさ自由）で、メイン窓のタイムラインを見ながら流せる。表示中はスリープしない |
| 再生中の操作 | タイムラインに赤い再生位置の線が動く。帯をクリックするとその時刻の写真へ。メイン窓の下段に「一時停止 / 再開」「終了」。流している途中でクリップを動かしたり範囲・フェードを変えると、その場で音に反映 |
| 試聴 | クリップの編集行の「試聴」で、その範囲だけを鳴らす（波形の上に再生位置） |
| 操作 | **Space** 停止 / 再開、**← →** 前へ / 次へ、**Esc** 終了 |
| 表示時間 | 0.3 / 0.5 / 0.7 / 1 / 1.5 / 2 / 3 / 4 / 5 / 7 / 10 / 15 / 20 / 30 秒 |
| 切り替え | Ken Burns / クロスフェード / スライド / ズーム / なし。長さは 0.3〜3 秒（表示時間より長くはしない） |
| 順番 | 名前順 / 撮影日順（EXIF、なければファイルの作成日）/ ランダム |
| 表示 | 全体を表示（余白は黒）/ 画面いっぱい（はみ出しを切る） |
| そのほか | 繰り返し、サブフォルダも含める。前回のフォルダを次回も開く |

読めるのは macOS の ImageIO が読める画像（JPEG, HEIC, PNG, TIFF, RAW など）。SVG は対象外。
EXIF の向きは反映する。画面サイズに合わせて縮めて読むので、大きな写真でも軽い。

## 使い方

1. 写真のフォルダをウインドウにドロップ（複数可。写真そのものを落としてもよい）。
2. 途中から見たければ、サムネイルをクリック（見出しに「開始: N 枚目」と出る。× で最初からに戻る）。
   ⌘クリックや ⇧クリックで 2 枚以上選ぶと、見出しが「選んだ N 枚だけを流します」になり、その写真だけを流す。
   ランダムのときも、開始写真を決めていればそれを最初に出してから混ぜる。
3. 表示時間や切り替えを決めて「スライドショーを開始」（Return または ⌘Return）。
4. Space で止める／動かす。止めると画面下に「一時停止 N / 総数 ファイル名」が出る。
   ← → で送る（止めたままでも送れる）。Esc か Q で終わる。
5. 音楽を付けるなら、音声ファイル（mp3 / m4a / wav など）をタイムラインに落とす。落とした位置から鳴る。
   ドラッグで動かせる（写真の区切りに吸着）。クリックすると、置く位置・音量と、曲全体の波形の帯が出る。
   波形の帯では、縦のつまみで曲の開始位置・終了位置を、上の丸いつまみでフェードイン／アウトの長さをドラッグで決める
   （数値欄でも直せる）。タイムライン上のクリップの両端をつまむと、頭・終わりを削ることもできる。
   何本置いてもよい。段は常に 2 段以上あり、段ごとに色が違う。一番下の空いた段に落とすと新しいトラックになる。クリップを上下にドラッグしても段を移せる。
   同じ段で時間が重なっているクリップは、開いたときや追加したときに自動で別の段へ振り分ける。
   段を分けて重ねれば混ざるので、前の曲のフェードアウトと次の曲のフェードインを重ねるとクロスフェードになる。
   全画面では、最初・矢印で飛んだとき・最初に戻ったときだけ写真の位置に曲を合わせ、
   あとは曲を触らずに流す（毎回合わせ直すと音が飛ぶため）。
6. 動画にしたいときは「mp4 に書き出す…」（⇧⌘E）。サイズとフレームレートを選んで保存先を決めると、
   今の設定（表示時間・切り替え・順番・選んだ写真・表示のしかた・タイムラインの音声）のまま mp4 ができる。
   最後は切り替えの長さぶん黒にフェードし、音声もフェードアウトして終わる。途中で「中止」できる。
7. ⌘S で **.cpsd 書類**に保存（⇧⌘S で別名）。設定・タイムラインが入り、音声ファイルは書類の中の `audio/` にコピーされる。
   保存ダイアログの「写真も書類の中にコピーする」をオンにすると（既定）、開いている写真を全部（パネルで外したものは除く）
   `photos/` に順番を保ってコピーし、以後はその写真を元にする（フォルダを動かしても開ける）。⌘O やドロップ、ダブルクリックで開ける。

## 構成

```
CacaoPhotoSlide/
├── project.yml                     # XcodeGen の定義（ここから .xcodeproj を生成）
├── CacaoPhotoSlide.xcodeproj       # 生成物（xcodegen generate で再生成できる）
├── bump-version.sh                 # 配布用ビルドの前に 0.0.1 上げる
├── make-dmg.sh                     # 配布用 dmg を作る（背景は dmg/make-background.swift で生成）
├── icon/make-icon.swift            # アプリアイコンを描くスクリプト
├── dist/                           # ビルド済み: *.app / *.dmg
└── CacaoPhotoSlide/                # Mac アプリ（SwiftUI）
    ├── CacaoPhotoSlideApp.swift    # エントリ・メニュー・Dock へのドロップ受け取り
    ├── AppModel.swift              # フォルダ・写真一覧・設定の保存・スライドショーの起動
    ├── PhotoLibrary.swift          # フォルダから画像を集めて並べる（EXIF の撮影日）
    ├── ImageLoader.swift           # 画面サイズに縮めて読み、前後 2〜3 枚をキャッシュ
    ├── SlideshowController.swift   # 再生の状態（今の写真・前の写真・停止・Ken Burns の動き）
    ├── SlideshowWindow.swift       # 画面を覆う窓。キー操作、カーソル／メニューバーを隠す
    ├── TransitionMath.swift        # 切り替えの式（画面と mp4 で共用）と、Core Graphics で 1 コマ描く部分
    ├── VideoExporter.swift         # AVAssetWriter で H.264 の mp4 に。音声はクリップごとの合成トラックをミックスして AAC で
    ├── Project.swift               # クリップ（MusicClip）と .cpsd 書類（project.json + audio/）
    ├── MusicTimeline.swift         # 全画面でタイムラインどおりに鳴らす（写真の位置から時刻を決める）
    ├── Waveform.swift              # 曲の波形（8 kHz モノラルで読んで山の高さに）
    ├── Settings.swift              # 切り替え・順番・表示の種類と設定キー
    └── Views/
        ├── ContentView.swift       # メイン窓（ドロップ・サムネイル・選択・設定・開始）
        ├── AudioTimelineView.swift # タイムライン（ルーラー・写真の区切り・クリップの配置と編集、両端のつまみ）
        ├── ClipRangeView.swift     # 曲全体の波形の上で、開始位置・終了位置・フェードをつまむ
        ├── ExportSheet.swift       # mp4 書き出しの設定と進み具合
        └── SlideshowView.swift     # 全画面の描画
```

### 描画のしくみ

SwiftUI のアニメーションには頼らず、`TimelineView` で毎フレーム「今の時刻」をもらい、
今の写真を出し始めた時刻からの経過で、切り替えの進み具合と Ken Burns の位置を自分で計算する。
こうすると Space で止めたときに動きもその場で止まり、再開すると続きから動く。
停止中に ← → で送ったときは、切り替えだけは実時間で最後まで動かし、新しい写真は出だしで止めておく。
mp4 の書き出しも同じ式を使い、1 コマずつ時刻を進めて Core Graphics で描き、AVAssetWriter に渡す。

### .cpsd の中身

```
名前.cpsd/
├── project.json    # 写真フォルダ（絶対パス）、選んだ写真、外した写真、表示時間・切り替え・順番など、書き出しの設定、クリップ（曲の範囲・フェード）、includesPhotos
├── audio/          # タイムラインに置いた音声ファイルのコピー（project.json からは audio/xxx の相対パス）
└── photos/         # 「写真も書類の中にコピーする」で入れた写真。0001_ の連番で順番を保つ（あればこちらを写真の元にする）
```

写真を入れなかったときは場所だけを持つ。フォルダを動かすと「写真のフォルダが見つかりません」になるので、開き直してフォルダを落とす。

## ビルド

必要: Xcode、XcodeGen（`brew install xcodegen`）。

```bash
cd ~/CacaoApps/CacaoPhotoSlide
./bump-version.sh                         # 配布用ビルドのたびにバージョンを 0.0.1 上げる
xcodegen generate                         # project.yml を変えたときだけ
xcodebuild -project CacaoPhotoSlide.xcodeproj -scheme CacaoPhotoSlide -configuration Release \
  -derivedDataPath build/DerivedData build
rm -rf dist/CacaoPhotoSlide.app && cp -R build/DerivedData/Build/Products/Release/CacaoPhotoSlide.app dist/
./make-dmg.sh                             # dist/CacaoPhotoSlide-<version>.dmg
```

署名していないので、初回は Applications 内のアプリを右クリック →「開く」。
